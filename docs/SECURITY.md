# 本机插件、下载信任与播放代理

## 插件与 Node.js

订阅脚本是用户选择的本机 Node.js 程序，会以当前用户身份运行。应用不会默认传入完整父进程环境：只保留 PATH、平台运行所需变量、语言变量和证书路径变量。设置里的“高级兼容模式”会完整继承父环境，可能传递 HTTP(S) 代理凭据、访问令牌等秘密。

“检测 Node 权限标志”只检查所选 Node 的 `--help` 文本，既不启用权限限制，也不验证它能否隔离恶意程序。**当前没有可选的 Node 权限执行模式**；该功能延期至 Node 18+ 版本矩阵与插件兼容性完成验证之后。Node 18+ 版本间权限模型能力不同，本应用不把该模型作为安全边界。日志会遮盖常见 URL 凭据、token、Cookie、Authorization 和签名参数；未知插件自定义格式的秘密无法保证被识别。

## 可选日志持久化

设置中的“持久化脱敏日志”默认关闭。开启后只将 `Player.log` 已执行常见规则脱敏后的行追加到应用数据目录 `logs/player.log`；行带 RFC3339 UTC 时间戳，单行（含换行）最多 4096 字节，单文件最多 1 MiB，保留当前文件和 3 个轮转文件（总计最多 4 MiB）。文件使用 0600、目录使用 0700 权限（平台支持时）。日志读取时只返回最近 7×24 小时的行，并清理过期行；应用启动时也清理一次。追加写入期间至少每小时清理一次；日志关闭且应用保持运行、无人读取时，过期文件会留到下一次启动或读取，但不会展示过期行。4 MiB 容量上限可能更早丢弃日志。关闭设置后，保存返回时停止后续磁盘写入；磁盘错误被忽略，不影响播放，内存日志仍可用。日志页可清除内存与这些固定名称的日志文件，操作不触及 pin、history 或插件配置。

脱敏只覆盖应用已知的常见凭据写法，插件可输出未知格式或任意秘密；持久化并不代表日志已完全匿名。用户应只在有需要时打开并自行检查插件输出。

## 下载校验与首次信任

应用继续读取插件源发布的 MD5，以维持既有协议。严格 MD5 模式会在替换本机缓存之前拒绝不匹配文件。MD5 与脚本来自同一发布位置时不能证明发布者身份。

应用另计算 SHA-256 并保存到每个订阅的 `subs/<id>/source/pin.json`：

- 首次使用时，展示来源和 SHA-256；只有用户批准后才启动脚本。
- 已批准 URL 的内容哈希发生变化时，先停掉当前插件并要求用户再次批准。拒绝后新版本不会执行。
- 修改订阅 URL（包括同一内容换地址）会重新要求确认。
- 用户确认后保存的新 pin 表示本机接受该字节内容，不代表独立认证的发布者签名。

TOFU 无法保护首次下载免受恶意源站、受控 DNS 或首次下载链路被攻陷。 pin 文件损坏时应用失败关闭并报告错误，不自动重建信任。

## 外部播放器

内置播放器在本机窗口里加载页面，脚本和关闭请求只访问 loopback 上的剧集服务（`/hls.min.js`、`/ep/...`、`POST /player/close`）。`/player/close` 只关闭这个播放窗口。`?direct=1` 返回的是原先 302 会跳到的同一个本地代理地址。内置播放器以外的程序只收到本地代理 URL 或连播 M3U。SenPlayer 通过 `open -b <bundle id>` 接收 `senplayer://x-callback-url/play?url=`，URL 是单个参数。自定义播放器是用户在设置里选定的本机程序：macOS `.app` 经 `open` 启动，其他平台直接执行该文件。附加参数按引号拆成 argv，`{url}` 替换成一个参数；不调用 shell，不展开变量、命令替换或通配符。保存和播放前会检查路径存在且可执行（Windows 为 `.exe`，macOS 应用程序包需含 `Contents/Info.plist`）。用户选择的程序以当前用户身份运行，应用不把它当作沙箱。

## 本地播放代理

代理仅能访问应用经插件 `play` 响应校验后登记的目标。网络接口不接受客户端提供任意 `u=` 目标或 `h=` 请求头。代理 URL 只携带高熵随机 opaque ID，ID 映射到服务端保存的 URL、头和会话；ID 两小时到期，订阅重载或停止会撤销现有映射。URL 文件名只为兼容播放器解复用器保留扩展名，不参与目标选择。

HLS 主清单、variant、密钥及分片使用同一会话映射。允许公网 CDN 重定向；跨域重定向到本机或私网地址默认拒绝。插件 `play` 明确返回的 loopback 媒体端口可使用；同源插件服务路由由应用重定位。设置中的“允许播放局域网媒体地址”是明确的用户授权，会允许该播放会话中的 LAN 媒体和重定向目标。它默认关闭。

代理仍为已登记 opaque ID 的媒体响应提供 `Access-Control-Allow-Origin: *`，以兼容内置播放器。该头不再伴随客户端可控上游目标。Origin/token 检查不是唯一授权机制；同源恶意代码若能取得有效播放 URL，或本机进程窃得有效 ID，仍可能在其有效期内访问对应资源。

## LAN 插件 API

“允许局域网访问”将插件 HTTP 服务绑定到所有网络接口，可能让其他设备调用插件 API 和其代理路由。此项默认关闭，与局域网媒体播放授权分开。变更设置时先同步停止旧进程，再由界面尝试按新绑定重载；重载失败不会保留旧的公网/LAN 监听。

## 网页模式

`--web` / `JSTV_MODE=web` 把同一套 Go 服务暴露给浏览器。桌面进程不启用这套登录。

- 管理员密码只以 bcrypt 形式写在数据目录 `auth.json`（权限 0600）。`JSTV_WEB_PASSWORD` 只在第一次创建，或显式设置 `JSTV_WEB_RESET_PASSWORD=1` 时使用。
- 会话 cookie 为 HttpOnly、`SameSite=Lax`。`JSTV_WEB_SECURE=1` 时附加 `Secure`，应与 HTTPS 一起使用。服务端会话记录只保存令牌的 SHA-256，默认 12 小时滑动、最长 7 天。
- 除登录页、登录接口和仅返回 `ok` 的 `/healthz` 外，界面、JSON 接口、`/media` 播放和 `/poster` 海报都要带有效会话。播放清单里的地址改写成同源 `/media/...`，不把上游 URL 和请求头交给浏览器。
- 修改类接口要求 `Content-Type: application/json` 和 `X-JSTV-Request: 1`，避免其他网站用表单带上 cookie。
- 海报代理拒绝回环、私网和链路本地地址，只额外放行当前插件进程自己的 loopback 端口。不代理插件返回的 HTML 页面到本站源上。
- 登录用户仍然可以让容器执行自己添加的 Node 插件。登录限制的是谁能操作界面，不是插件的权限。

## 验证范围

自动化测试使用仓库 mock 插件和本地 `httptest` fixture；它们验证 HTTP 接口、opaque 授权、HLS 改写、Range、重定向和状态撤销，以及网页模式的登录、退出、未登录拒绝和播放地址改写。不代表真实 CDN、真实第三方插件或真实播放器端到端播放已经验证。浏览器 PNA/LNA 提示及平台防火墙行为仍取决于运行环境。
